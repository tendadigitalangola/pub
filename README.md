# Tenda Digital — Publicações

Repositório público para páginas e artefactos institucionais da Tenda Digital.

## Estrutura

Cada iniciativa pública deve ocupar uma pasta própria na raiz do repositório, com ficheiros estáticos autocontidos e rotas estáveis.

- `/cyber-parceiros/` — Landing page oficial do programa Cyber Parceiros.

A publicação é feita por GitHub Pages através do workflow em `.github/workflows/pages.yml`.
